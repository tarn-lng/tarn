# Contributors

Thank you to everyone who helps build Tarn. Every fix, test, doc tweak, bug
report and idea makes the language better for the people (and agents) who use
it. This file is where we say thanks by name.

## Contributors

*This list is waiting for its first name. Could it be yours?* 🎉

Pick a [`good first issue`](https://github.com/tarn-lng/tarn/labels/good%20first%20issue),
say hi in the issue so nobody duplicates work, and send a PR.

## How to get added

- Any merged pull request earns you a spot here.
- Add yourself in your own PR: append a line like
  `- [@your-handle](https://github.com/your-handle)` under **Contributors**.
- Forgot? No problem. A maintainer will add you when your PR is merged.
